# SkillConnect

SkillConnect is a web-based platform that connects candidates with suitable job opportunities based on their skills and profiles.

## Features

- Candidate profile and details
- Job listing and job details
- Skill-based candidate matching
- MongoDB/CongoDB database integration
- Dynamic web pages using HTML, CSS and JavaScript
- Python backend using Flask

## Technologies Used

- Python
- Flask
- MongoDB / MongoDB Atlas
- HTML
- CSS
- JavaScript
